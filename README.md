# Citadelle Options

Institutional derivatives infrastructure built on the Robinhood Chain.
Trade options and perpetuals on tokenized US equities with deep liquidity, USDC cash settlement, and live Pyth oracles.

## Tech Stack
- Frontend: React + Vite + Wagmi
- Blockchain: Robinhood Chain (EVM)
- Oracles: Pyth Network
- Settlement: USDC
